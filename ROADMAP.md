# Gangwar Development Roadmap 🗺️

This document outlines the planned features, improvements, and milestones for the Gangwar Flutter project.

## 🟢 Phase 1: Core Experience (Complete)
- [x] Full migration of original Kotlin logic to Dart.
- [x] Cross-platform UI implementation (Android, iOS, Linux, Web).
- [x] Flame Engine integration for the 3D Open World.
- [x] Basic combat system and drug economy.
- [x] Procedural Pixel Art and Animation systems.
- [x] Build system automation (Makefile).

## 🟡 Phase 2: Polish & Content (In Progress)
- [ ] **Sound & Music**: Implementation of a retro-synth soundtrack and 8-bit sound effects.
- [ ] **Advanced Combat**: Adding "Special Moves" and gang-wide tactical commands.
- [ ] **Enhanced NPCs**: More diverse interaction types and quest-giving characters in the 3D world.
- [ ] **Dynamic Environment**: Time-of-day system affecting drug prices and police activity.
- [ ] **Visual Polish**: Shader-based CRT effects for a more authentic retro feel.

## 🟠 Phase 3: Social & Extended Gameplay
- [ ] **Multiplayer Elements**: Global leaderboards and "Gang Turf" wars via Firebase.
- [ ] **Achievement System**: Unlockable skins and titles for players.
- [ ] **Expanded City**: More locations (Hospital, Police Station Interiors, Underground Fight Clubs).
- [ ] **Modding Support**: External JSON-based loading for custom items and events.

## 🔴 Phase 4: Release & Optimization
- [ ] **Google Play / App Store Deployment**: Finalizing app bundles and store assets.
- [ ] **Performance Optimization**: Profile and optimize Flame rendering for low-end mobile devices.
- [ ] **Localization**: Support for Spanish, Portuguese, and Japanese.
- [ ] **PWA Support**: Full Progressive Web App implementation for browser-based play.
